# Video Spec

## Overview
- **Title**: Deploy in One Click — Product Demo
- **Purpose**: Show one-click deploy and drive free tier signups
- **Audience**: Developers and technical PMs
- **Target Duration**: 14.5s
- **Platform**: Instagram Reels

## Format
- **Resolution**: 1080x1920
- **FPS**: 30
- **Orientation**: Vertical

## Structure
### Scene 1: Hook (beat-01, beat-02)
- objective: Grab attention with a question, then reinforce with negatives
- visual: Avatar full-screen (beat-01), strike-through text (beat-02)
- text: "ONE CLICK deploy" / "No pipelines. No waiting."
- timing: 0.0s–5.2s

### Scene 2: Demo (beat-03)
- objective: Show the deploy button interaction
- visual: Deploy button screenshot with fade transition, whoosh SFX
- timing: 5.5s–8.8s

### Scene 3: CTA (beat-04)
- objective: Drive action
- visual: Avatar returns, success animation in lower third, CTA text
- text: "Try it free"
- timing: 9.2s–14.5s

## Style Notes
- caption style: Bold, mobile-safe, background pill
- transition style: Single fade into demo, cuts elsewhere
- avatar usage: Full-screen for hook and CTA, hidden during demo
- demo usage: Static screenshot cropped for clarity
- SFX usage: Single whoosh on deploy button click (beat-03)
