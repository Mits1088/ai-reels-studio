# Reel Script

## Voiceover Script

### Hook
**beat-01** (0.0s–2.8s): "What if you could deploy in one click?"

### Body
**beat-02** (3.0s–5.2s): "No pipelines. No waiting."

### Proof / Demo
**beat-03** (5.5s–8.8s): "Just hit this button and you're live."

### CTA
**beat-04** (9.2s–14.5s): "Try it free. Link in bio."

---

## Script Notes
- Hook is a direct question — grabs attention by addressing a pain point.
- Body uses short, punchy negatives for rhythm.
- Demo beat shows the actual UI interaction.
- CTA is clear and minimal.

## Timing Intent
- **Target duration**: 14.5s
- **Estimated words**: 26
- **Expected pace**: Conversational, slightly fast

## Visual Notes by Section
- **Hook**: Avatar full-screen, bold text overlay "ONE CLICK"
- **Body**: Strike-through text animation (no pipelines, no waiting)
- **Proof / Demo**: Deploy button screenshot with cursor, whoosh SFX on click
- **CTA**: Avatar returns with CTA text overlay, success animation in lower third
